Manual Data Validation

Review any data before allowing it to affect crop rankings. Only Approved records are applied. The original downloaded data stay unchanged. This editor runs on your own computer.

Enter or review a value

Planting months: enter a comma-separated list of month numbers 1–12. Use the exact scientific name shown in the AgriVerse catalog. Dataset review: type the filename in Value, choose an approval status and provide source notes. Crop rotation and irrigation notes are saved for review but are not automatically used as hard filters.
